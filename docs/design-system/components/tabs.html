Tabs

Tabs switch between sibling views without leaving the page.

WCAG 2.2 AAStatus: core, unused in mocksAPG Tabs

Overview

Use for two to six peer views. Never for steps in a process; use a stepper.

Anatomy

  1. Selected tabInk underline.
  2. TabMuted label.

Variants

With counts.
HTML
<div class="tabs" role="tablist" aria-label="Requests"><button class="tab" role="tab" aria-selected="true" type="button">New <span class="badge">4</span></button><button class="tab" role="tab" aria-selected="false" tabindex="-1" type="button">Replied</button><button class="tab" role="tab" aria-selected="false" tabindex="-1" type="button">Archived</button></div>

Sizes

One size; 44px tall.

States

Pointer and focus states are forced with data-state so they can be reviewed without a mouse; real pages get them from :hover, :focus-visible and :active. Everything else uses the real attribute.
