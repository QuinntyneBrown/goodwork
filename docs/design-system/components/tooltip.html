Tooltip

Tooltips name icon-only controls. They never hold anything a person must read to succeed.

Overview

Use only to label icon buttons or show a full value that was truncated.

Anatomy

  1. BubbleInverse surface, caption text.
  2. TriggerThe control it names.

Sizes

One size.

States

Pointer and focus states are forced with data-state so they can be reviewed without a mouse; real pages get them from :hover, :focus-visible and :active. Everything else uses the real attribute.
