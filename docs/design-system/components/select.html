Select

A native select picks one option from five or more. Fewer than five? Use a radio group so all choices are visible.

WCAG 2.2 AAStatus: core, unused in mocksNative <select>

Overview

Use for a known list like organisation type. The native control gives the right picker on every phone.

Anatomy

  1. LabelNoun.
  2. ChevronDrawn with CSS gradients in currentColor.

Variants

With a placeholder option.
HTML
<div class="field"><label class="field__label" for="se1">Organisation type</label><select class="select" id="se1"><option value="">Choose one</option><option>Non-profit</option><option>Church or ministry</option><option>Social enterprise</option><option>Small business</option><option>Other</option></select></div>

Sizes

Matches the text field sizes.

HTML
<label class="visually-hidden" for="ss1">Small</label><select class="select input--sm" id="ss1"><option>Small</option></select><label class="visually-hidden" for="ss2">Medium</label><select class="select" id="ss2"><option>Medium</option></select><label class="visually-hidden" for="ss3">Large</label><select class="select input--lg" id="ss3"><option>Large</option></select>

States

Pointer and focus states are forced with data-state so they can be reviewed without a mouse; real pages get them from :hover, :focus-visible and :active. Everything else uses the real attribute.
