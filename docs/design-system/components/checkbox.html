Checkbox

Checkboxes let people pick any number of options, such as which services they are interested in.

Overview

Use for independent choices. Use a switch for a setting that takes effect immediately, and a radio group for one-of-many.

Anatomy

  1. Box20px, Ink when checked.
  2. LabelClickable.
  3. DescriptionOptional, muted.

Variants

What do you need?
A group in a fieldset with a legend.
HTML
<fieldset><legend>What do you need?</legend><label class="choice"><input type="checkbox" checked><span>Web or mobile app</span></label><label class="choice"><input type="checkbox"><span>Website</span></label><label class="choice"><input type="checkbox"><span class="choice__text">Not sure yet<small>We will help you work it out</small></span></label></fieldset>

Sizes

One size: 20px box in a 24px row.

States

Pointer and focus states are forced with data-state so they can be reviewed without a mouse; real pages get them from :hover, :focus-visible and :active. Everything else uses the real attribute.

Responsive behaviour

  • Groups stack vertically at every width.
  • The whole label row is the target.

Theming

Checked fill is --color-accent; the tick uses --color-fg-on-accent.

Accessibility

Role and pattern

Native input type="checkbox" inside <label>; groups in <fieldset> with <legend>.
