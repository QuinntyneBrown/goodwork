Brand lockup

The lockup pairs the Cornerstone mark with the serif wordmark. Three ink blocks and one gold cornerstone.

WCAG 2.2 AAStatus: stableCornerstone mark

Overview

The mark's ink blocks use currentColor, so the same SVG renders Ink on Linen and Linen on Ink. The gold block never changes; it is the one note of gold in the mark.

Anatomy

  1. Ink blockscurrentColor.
  2. Cornerstone--color-brand-gold, bottom left.
  3. WordmarkSource Serif 4, semibold.
