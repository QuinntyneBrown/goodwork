Toast

Toasts confirm background actions without taking focus.

Overview

Not used by the brochure, which confirms inline. Use in apps for saves and undoable actions. Errors never auto-dismiss.

Anatomy

  1. IconInherits text colour.
  2. MessageWhat happened.
  3. ActionUndo or View.

Sizes

One width: 384px from 640px up.

States

Pointer and focus states are forced with data-state so they can be reviewed without a mouse; real pages get them from :hover, :focus-visible and :active. Everything else uses the real attribute.

Core component. The brochure mocks do not use it yet; it is specified from the mocks' shared kit (docs/mocks/assets/ui.css, now assets/components.css) so the next screen built for Goodwork does not have to invent it. See the mock gallery.
