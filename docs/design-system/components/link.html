Link

Links go places: another page, a section, an email address. They are always underlined so colour is never the only cue.

Overview

Use a link for navigation and for mailto: addresses like the footer's hello@goodwork.dev. Use a button when something changes. A link styled as a button is still a link.

Anatomy

  1. TextSays where it goes, readable out of context.
  2. Underline1px, 0.15em offset; 2px on hover.

Sizes

Links inherit the size of the text they sit in.

States

Pointer and focus states are forced with data-state so they can be reviewed without a mouse; real pages get them from :hover, :focus-visible and :active. Everything else uses the real attribute.

Responsive behaviour

  • Long addresses wrap anywhere with overflow-wrap: anywhere inside narrow footers.
  • Standalone links get at least 24px of tap height from line height.

Theming

Links read --color-fg-link (Ink in light, Linen in dark) and turn gold on hover (--color-fg-link-hover).
