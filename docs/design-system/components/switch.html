Switch

A switch changes a setting the moment it is flipped, with no save button.

WCAG 2.2 AAStatus: core, unused in mocksrole="switch"

Overview

Use for settings that apply instantly. In a form that is submitted later, use a checkbox.

Anatomy

  1. Track and thumb44×24px.
  2. LabelNames the setting.

Variants

Label right (default) and label left.
HTML
<label class="switch"><input type="checkbox" role="switch" checked><span>Email me project updates</span></label><label class="switch"><span>Dark theme</span><input type="checkbox" role="switch"></label>

Sizes

One size.

States

Pointer and focus states are forced with data-state so they can be reviewed without a mouse; real pages get them from :hover, :focus-visible and :active. Everything else uses the real attribute.

VariantOffOnFocusDisabled
Switch

Both themes

Responsive behaviour

  • Label and switch stay on one row; the label wraps.

Theming

Off track is --color-border-strong; on is --color-accent.

Accessibility

Role and pattern

Motion

Thumb slides over --duration-base.

Touch

Row is at least 24px.

Content

  • Name the setting: Email me project updates.
  • Never pair a switch with a Save button.
