Form field

The form field fixes the order and spacing of label, control, help and error so every form reads the same.

WCAG 2.2 AAStatus: stableLayout primitive

Overview

Every input, select and textarea sits in .field. The spacing between parts is --space-1; between fields it is --space-4.

Anatomy

  1. LabelWith (required) in words.
  2. ControlAny input.
  3. HelpOptional.
  4. ErrorIcon plus text, after help.

Variants

Leave blank if you are an individual.

Optional field with help.
HTML
<div class="field" style="width: 100%;"><label class="field__label" for="ffv">Organisation <span class="optional">(optional)</span></label><input class="input" id="ffv" aria-describedby="ffv-h"><p class="field__help" id="ffv-h">Leave blank if you are an individual.</p></div>

Sizes

Follows its control's size.

States

Pointer and focus states are forced with data-state so they can be reviewed without a mouse; real pages get them from :hover, :focus-visible and :active. Everything else uses the real attribute.

Responsive behaviour

  • Always single column; two-column field rows only above 768px for short pairs like first and last name.

Theming

Help text is --color-fg-muted; errors are --color-danger-fg.
