Alert

Alerts carry the contact form's outcomes: the error summary, the send failure and the confirmation.

WCAG 2.2 AAStatus: stablerole="alert" or status

Overview

Use for messages that belong to a region of the page. Success uses role="status"; new errors use role="alert".
