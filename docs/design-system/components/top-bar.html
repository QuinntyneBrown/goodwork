Top bar

The top bar carries the Goodwork lockup and a single Start a project action. On a one-page site there is nothing else to navigate to.

Overview

Marketing pages use the lockup plus one primary link. App screens add a menu button, search and account actions; those variants are specified here for when Goodwork builds them.

Anatomy

  1. Brand lockupLinks home; see brand lockup.
  2. Call to actionOne primary link to the contact form.

Sizes

One height: <code>--layout-topbar-height</code> (56px).

States

Pointer and focus states are forced with data-state so they can be reviewed without a mouse; real pages get them from :hover, :focus-visible and :active. Everything else uses the real attribute.

Responsive behaviour

  • Sticky at the top at every width.
  • At 360px the lockup and button still fit on one row; the button never shrinks below 40px.

Theming

Background --color-bg-surface with a --color-border-default rule. The lockup's ink follows currentColor, so it reverses to Linen in dark while the gold block stays gold.

Accessibility

Role and pattern

<header> landmark. The menu button uses aria-expanded and aria-controls.

Keyboard

KeyAction
TabSkip link, brand, then the call to action.

Focus

Shared ring. The sticky bar never covers the focused element; use scroll-padding-top equal to its height.

Labelling

Brand link is named Goodwork, home.
