Foundation

Iconography

Outline icons on a 24-unit grid, 2px stroke, in currentColor.

WCAG 2.2 AAStatus: stable
  • Overview
  • Icon set
  • Usage
  • Tokens

Overview

Icons are inline SVG so they theme with text. The brochure uses two, a monitor and a globe, in gold on the service cards; status icons appear in alerts.

Icon set

pluscheckalertinfowarnxsendmonitorglobemailmenumoreedittrashsearcharrow-rightexternalfolderwifi-offlockhomeuserscalendarheartdownload

Usage

  • Sizes 16, 20 and 24px via .icon--sm, .icon, .icon--lg.
  • Decorative icons are aria-hidden; icon-only buttons are labelled.

Tokens

Icons have no tokens of their own; they inherit colour and size from text. See colour.
