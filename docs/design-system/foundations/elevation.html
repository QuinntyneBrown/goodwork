Foundation

Elevation

Four shadows and a surface ladder. In dark, surfaces get lighter as they rise.

WCAG 2.2 AAStatus: stable
  • Overview
  • Shadows
  • Z-order
  • Usage
  • Tokens

Overview

Cards use shadow 1 on Paper. Menus use 3, dialogs 4. In dark, the canvas is Ink, cards are ink-700 and raised surfaces ink-600, so height reads without relying on shadow.

Usage

  • Components never set a raw z-index.
  • Shadows are tinted with Ink in light, black in dark.
