Foundation

Motion

Quiet motion that explains change. Nothing animates on page load.

WCAG 2.2 AAStatus: stable
  • Overview
  • Durations and easing
  • Usage
  • Accessibility
  • Tokens

Overview

The brochure moves only on interaction: button hover, focus ring, the busy spinner. Dialogs and toasts are specified for apps.

Durations and easing

Usage

  • Hover 120ms, reveal 200ms, dialogs 320ms.
  • Nothing over 500ms except progress.

Accessibility

  • prefers-reduced-motion zeroes durations in the tokens, so components need no extra queries.
  • Smooth scrolling to the contact form is turned off under reduced motion.
