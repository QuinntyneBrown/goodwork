Spacing

A 4px scale. Small steps inside components, big steps between sections.

WCAG 2.2 AAStatus: stable
  • Overview
  • Scale
  • Usage
  • Tokens

Overview

All padding, margins and gaps come from --space-*. The brochure's rhythm: 4px inside a field, 16px between fields, 20px inside the hero, 40px between sections.

Usage

  • Inside components: --space-1 to --space-6.
  • Between sections: --space-8 and up.
  • Control heights 32, 40 and 48px set button and input sizes.
