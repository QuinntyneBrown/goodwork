Accessibility

WCAG 2.2 AA by construction. These are the commitments every component page answers.

WCAG 2.2 AAStatus: stable
  • Overview
  • Commitments
  • Focus ring
  • Testing
  • Tokens

Overview

Contrast is checked mechanically for both themes. Structure, labels and names are checked by the design-system checker. The rest is a manual pass on every release.

Commitments

  • Text 4.5:1, large text and UI edges 3:1, in both themes (1.4.3, 1.4.11).
  • Status is colour plus icon plus words (1.4.1).
  • Reflow to 320px with no sideways scroll (1.4.10).
  • Everything works with a keyboard; one gold focus ring at 3:1 or better (2.1.1, 2.4.7, 2.4.11).
  • Targets at least 24px, primary mobile actions 44px (2.5.8).
  • A skip link and landmarks on every page (2.4.1).
  • Visible labels; required stated in words; errors say how to fix and link from a summary (3.3.1–3.3.3).
  • Native elements first; ARIA follows the APG patterns named per component (4.1.2).
  • Status messages in live regions (4.1.3).
  • Motion respects reduced-motion preferences (2.3.3).

Focus ring

hello@goodwork.rocks

The ring is gold-700 in light and gold-300 in dark. Raw Cornerstone Gold fell under 3:1 on Linen, so it was darkened for focus.

Testing

  • Run the contrast and structure checks.
  • Tab through the brochure: skip link, brand, Start a project, email, message, Send request, footer email.
  • Use a screen reader on the invalid and sent states.
