Overview

Themes override semantic tokens only. [data-theme="dark"] forces dark; otherwise prefers-color-scheme decides unless the page forces light. Each theme sets color-scheme.

Token tiers

  • Primitives (--palette-*): raw brand values.
  • Semantic (--color-* and friends): meaning; themes override these.
  • Component (--btn-bg…): scoped aliases in components.css.

Adding a theme

[data-theme="partner"] {
  --color-accent: var(--palette-gold-700);
  --color-fg-on-accent: var(--palette-paper);
}

Then add the theme's pairs to contrast-pairs.json and run the contrast check.

tokens.json

tokens/tokens.json is a DTCG export generated from tokens.css. Dark values live under $extensions.
