Data tables & lists

Tables compare; lists scan.

WCAG 2.2 AAStatus: stable

  • Structure
  • States
  • Responsive
  • Accessibility

Overview

The brochure lists two services. Apps will need a request inbox table.

When to use

  • Table: compare fields across records.
  • List: scan items with one or two lines.
  • Cards: few items with rich content, like services.

States

  • Loading rows as skeletons.
  • Empty first-run.
  • No results with a clear filters action.
  • Error with retry.

Responsive

  • Tables scroll inside their wrapper.

Accessibility

  • Caption, scope, aria-sort.

Content

  • Human dates; right-aligned numbers.
