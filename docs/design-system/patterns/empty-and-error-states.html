Pattern

Empty & error states

Say what happened, keep the person's work, and give one way forward.

WCAG 2.2 AAStatus: stable

Overview

The brochure's only error is a failed send. App screens add first-run, no-results and permission empties.

When to use

  • Inline alert for an action that failed.
  • Empty state for a region with nothing in it.
  • Error page when the whole page cannot load.

Structure

We couldn't send your request

Your message is still here. Try again, or email hello@goodwork.rocks.

States

  • First run.
  • No results.
  • Permission.
  • Failure with retry.

Responsive

  • Centred empties; alerts full width.

Accessibility

  • Errors are announced; focus moves to them after submit.

Content

  • Never blame. Never show a code alone. Always offer a fallback.
