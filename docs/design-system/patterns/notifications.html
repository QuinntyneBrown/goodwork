Pattern

Notifications

Tell people what changed without stealing their focus.

WCAG 2.2 AAStatus: stable

  • When to use
  • Structure
  • States
  • Responsive
  • Accessibility

Overview

The brochure confirms inline. Apps use toasts for background results and banners for persistent notices.

When to use

  • Toast: result of a background action.
  • Banner: a notice for the whole page.
  • Inline alert: outcome of a form.

Structure

Request archived

A toast with undo.
HTML
<div class="toast toast--success" style="animation: none;"><svg class="icon" aria-hidden="true" viewBox="0 0 24 24"><path d="m5 12 5 5L20 7"/></svg><div class="toast__body"><p class="toast__title">Request archived</p></div><button class="toast__action" type="button">Undo</button></div>

States

  • Info, success, warning, danger, stacked.

Responsive

  • Bottom full width on phones; bottom right above 640px.

Accessibility

  • Live regions; errors never auto-dismiss; timers pause on hover and focus.

Content

  • Past tense; one action.
