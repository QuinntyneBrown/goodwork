Navigation & page structure

One page, one header, one action. Landmarks in the same order everywhere.

Overview

The brochure is a single page: skip link, header, main with hero, services and contact, footer.

When to use

  • One-page sites: top bar with one call to action, anchor to the form.
  • Apps: top bar plus sidebar; breadcrumbs two levels deep.
